<h1 align="center">과즙 10% · Juice10</h1>

<p align="center"><b>오렌지 10%면 오렌지주스, 보정해도 나야 🍊</b></p>

## 이름의 의미

과즙이 10%만 들어 있어도 오렌지주스라고 부르듯이, 사진을 조금 보정해도 여전히 나라는 뜻입니다.
과하게 바꾸기보다 자연스럽게 다듬는 보정을 지향합니다.

## 어떤 앱인가요

맥(Apple Silicon)에서 쓰는 사진 보정 앱입니다.
포토샵의 유동화(Liquify)처럼 사진 속 형태를 손으로 밀고, 모으고, 부풀리고, 돌려서 다듬을 수 있습니다.

- 뒤틀기, 재구성, 매끄럽게, 오목, 볼록, 돌리기 도구
- 바꾸고 싶지 않은 부분을 고정하는 마스크
- 노출, 대비, 채도, 색온도 보정
- 원본 해상도로 JPG·PNG 저장

## 실행

```bash
npm install
npm start
```
